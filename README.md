# anomaly_detecction
# Классификация аномалий во временных рядах  

Проект разрабатывается в рамках исследований СПбПУ. Конфиденциальные данные заменены синтетическими аналогами.

**Проект:** Разработка ML-модели для детектирования аномалий в данных суперкомпьютера СПБПУ
(Программа ещё находится в разработке, тем не менее ключевой результат уже имеется)
##  **Описание**  
Проект решает задачу автоматического обнаружения аномалий  с помощью:  
- Преобразования сырых данных по всем операциям с суперкомпьютера к пригодному для обучения ML моделей виду
- Предобработки данных (нормализация, обработка пропусков, feature engineering).
- Классификации на 4 класса: `норма`, `Failed`, `Node_fail`, `Cancelled`.  
- Подбора оптимальных порогов классификации для ARIMA и бустинговых моделей, LSTM.  
- Основная задача - предварительно сказать как завершится конкретная операция,  которая только стартовала 
## 🛠 **Технологии**  
- **Python**: `pandas`, `numpy`, `scikit-learn`, `statsmodels`, `XGBoost`, `LightGBM`, "TensorFlow" 
- **Метрики**: `F1-weighted`, `Precision/Recall`  

##  **Результаты**  
- Достигнута **F1-score = Precision = Recall= 0.7** на тестовых данных (с дисбалансом классов 1:100).    
- Снижено количество ложных срабатываний на **35%** по сравнению с baseline-моделью.
